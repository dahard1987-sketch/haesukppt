# 복습 슬라이드 스튜디오

종이로 제출받은 학생 해석(숙제)을 바탕으로, 모범 해석과 학생들이 실제로 틀린 해석을 대조해서 보여주는 PPT를 자동으로 만들어주는 도구입니다. 빌드 과정이나 백엔드 서버가 필요 없는 순수 정적 HTML/CSS/JS라서, `sunsuck`처럼 GitHub 저장소에 올려 GitHub Pages로 배포하거나 다른 정적 호스팅에 그대로 올릴 수 있습니다. (입력 중인 내용은 교사 브라우저의 `localStorage`에만 자동 저장됩니다. 다른 기기로 옮길 필요는 없고, 최종 결과물은 "PPT로 내보내기"로 받는 실제 `.pptx` 파일입니다.)

## 로컬에서 미리 테스트하기

배포 전에 내 컴퓨터에서 먼저 확인하고 싶다면:

- 그냥 `index.html`을 브라우저로 더블클릭해서 열어도 대부분 동작합니다.
- 더 안정적으로 쓰려면 터미널에서:

  ```
  npm run serve
  ```

  후 `http://localhost:8000` 접속.

## GitHub Pages로 배포하기

1. 이 폴더를 새 GitHub 저장소로 올립니다 (`git init` → `git add` → `git commit` → `git remote add origin ...` → `git push`).
2. 저장소의 Settings → Pages에서 배포 브랜치(`main`)와 루트(`/`)를 지정합니다.
3. 잠시 후 `https://<계정>.github.io/<저장소이름>/` 주소로 접속하면 그대로 사용할 수 있습니다.

## 사용 흐름

### ① 원문 입력

지문을 문장 단위로 하나씩 추가합니다. 각 문장 카드에 **영어 원문**과 **모범 해석**만 입력하면 됩니다 (오답은 여기서 입력하지 않습니다). 문장 카드 사이의 "── 새 슬라이드 ──" 배지를 클릭하면 "── 같은 슬라이드로 묶기 ──"로 바뀌어, 짧은 문장 여러 개를 한 슬라이드에 모을 수 있습니다.

### ② 학생별 채점

학생 한 명의 종이 답안을 앞에 두고, "+ 학생 추가"로 그 학생을 등록한 뒤 위에서 아래로 문장 순서대로 쭉 입력합니다 — 문장마다 학생을 바꿔가며 종이를 계속 넘길 필요 없이, **한 학생의 답안지를 한 번에 끝까지** 훑으면서 입력하는 방식입니다. 맞은 문장은 비워두고, 틀린 문장만 오답을 입력하세요. 틀린 부분은 `[[이렇게]]` 대괄호 두 개로 감싸면 PPT에서 빨간색으로 강조됩니다. 짧은 코멘트(왜 틀렸는지)도 함께 적을 수 있습니다. 오답 입력창에서 `Enter`를 누르면 다음 문장 칸으로 바로 이동합니다. 학생 칩을 클릭해 다른 학생으로 전환하거나 이름을 입력할 수 있습니다.

### PPT로 내보내기

상단의 "PPT로 내보내기"를 누르면 실제 `.pptx` 파일이 다운로드됩니다. PowerPoint/Keynote/Google Slides 어디서든 바로 열립니다.

- 문장마다: 영어 원문 → (클릭) 오답 1 → (클릭) 오답 2 → ... → (클릭) 모범 해석이 **맨 마지막**에 공개되는 순서로 슬라이드가 이어집니다. 학생을 먼저 지목해 답을 맞혀보게 한 뒤 클릭으로 하나씩 공개하는 수업 흐름에 맞춘 구성입니다. (PPT 자체에 애니메이션 효과를 넣는 대신, 클릭/스페이스/화살표로 그냥 다음 슬라이드로 넘어가면 동일한 효과를 내도록 슬라이드를 여러 장으로 나눠 생성합니다.)
- 오답이 없는 문장은 영어 원문 슬라이드 다음 바로 모범 해석 슬라이드로 넘어갑니다.
- "── 같은 슬라이드로 묶기 ──"로 묶은 문장들은 한 슬라이드 안에서 순서대로 함께 공개됩니다.

## 테스트

```
npm test
```

`[[...]]` 오답 강조 파싱과 슬라이드 그룹핑 로직(`groupSentencesIntoSlides`, `slideStepCount`)을 `node --test`로 검증합니다.

## 관련 프로젝트

해석지(원문을 문장 단위로 나눈 손글씨용 인쇄물)를 만드는 [`sunsuck`](https://dahard1987-sketch.github.io/sunsuck/) 도구와 함께 사용합니다. 이 도구는 그 뒤 단계 — 걷은 손글씨 제출물을 수업 시간에 함께 복습하는 PPT — 를 담당합니다. 학생 제출물을 자동으로 가져오는 연동은 없으며, 교사가 직접 타이핑해서 입력합니다.
